# 匠人说 · 非遗生活

手机端交互原型，包含首页、作品识别、AI 非遗问答、体验跟学和个人手账。界面优先适配手机尺寸，也可在桌面浏览器中预览。

## 手机安装与分享

应用已加入 PWA 安装清单、主屏幕图标、原生分享按钮和基础离线缓存。要让其他人打开，需先把整个项目文件夹发布到一个支持 HTTPS 的静态网站托管平台；本地 `index.html` 文件不能直接生成可供他人访问的公共链接。发布后将 HTTPS 链接发给对方即可。安卓 Chrome 通常可从页面菜单选择“安装应用”；iPhone/iPad 请在 Safari 打开链接，点“分享”，再选“添加到主屏幕”。首次联网打开后，页面资源会缓存，之后可离线打开已缓存的界面。

## 本地预览

直接用浏览器打开 `index.html`。也可以在项目目录启动一个静态文件服务：

```bash
npx serve .
```

## 已实现流程

- 首页拍照/选图入口、热门非遗项目卡片、"和传承人聊两句"直达对话入口与底部导航。
- 底部导航含独立「问答」tab，可随时直接进入与 AI 传承人的对话界面。
- 识别页支持三种入口：拍照识别（现场拍照）、从相册选择（上传图库）、音频识别（录音或上传音频）；识别结果卡可继续查看百科、问传承人或进入跟学。
- 音频识别：可调用麦克风实时录音，或从相册/文件上传一段音频，识别声音类非遗（侗族大歌、古琴艺术、苏州评弹等）。
- 传承人问答：直接回答、口语化术语说明、参考资料折叠、建议追问、五轮对话上限和非遗范围提示。
- 扎染、漆扇、竹编体验项目；分步进度、操作易错提醒、mock 三档纠错反馈、断点续学和完成反馈。
- 跟学进度条支持点击任意步骤直接跳转（可回到上一步或跳到后续步骤）。
- 手账时间轴、看过/问过/做过筛选、记录详情与删除、门类/手作/问题统计、徽章和三款分享卡片。
- 手账和跟学进度保存在当前浏览器的 `localStorage` 中。

## Mock 范围

本地原型不调用相机、录音识别服务或大模型。上传的图片/音频用于触发演示识别流程，图片识别结果从内置的漆扇、扎染和竹编样例中模拟；音频识别结果从内置的声音类非遗（侗族大歌、古琴艺术、苏州评弹）样例中模拟；问答、跟学纠错、参考资料和分享均为演示数据。接入真实服务时，可替换 `app.js` 中 `identify`、`identifyAudio`、`renderAnswer` 和 `mockStepCheck` 的实现。
